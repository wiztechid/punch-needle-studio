# Punch Needle Studio

Punch Needle Studio is an English-language project and learning library for punch needle makers. It helps readers choose compatible materials, make usable projects, and troubleshoot common problems with clear instructions and honest evidence.

## Editorial moat

Our advantage comes from combining practical craft information with original, usable pattern assets and transparent setup notes:

- **Transfer-ready original patterns** with finished dimensions, a clear outline, color key, materials, and printing/transfer guidance.
- **Reproducible setup details** describing the needle/tool, fiber or thread, fabric, frame/tension, and finishing method where relevant.
- **Honest evidence labels** that distinguish hands-on tested guidance from reference-based or not-yet-tested work.
- **Useful troubleshooting** organized as symptom → checks → likely cause → fix → verification.
- **Connected learning paths** linking patterns, materials, techniques, and relevant fixes so readers can complete a project.
- **Trust-first recommendations** with clear affiliate disclosures and alternatives where appropriate.

## Publishing principles

1. Each page serves a distinct reader task and has one clear canonical home.
2. Similar queries belong together when they represent the same task; separate pages need a meaningful difference in intent or instructions.
3. Motif pages must offer genuinely distinct original patterns and useful project guidance. We do not publish thin pages that only swap a motif name or image.
4. Claims about dimensions, compatibility, testing, and results must match the evidence available.
5. Pattern files must be checked for rights, legibility, dimensions, and print/transfer usability.
6. Ads and affiliate elements must not obscure downloads, instructions, compatibility notes, or troubleshooting steps.
7. Reader feedback and submitted media are optional, reviewed, and used only with appropriate permission.

## Topic areas

- Beginner foundations and first projects
- Original patterns and seasonal projects
- Needles, fibers, fabrics, and compatibility
- Threading, stitches, finishing, and technique
- Symptom-led troubleshooting
- Carefully scoped projects for different surfaces

These are topic areas, not a commitment to create a page for every keyword. Content is published when the reader task, evidence, and useful page scope justify it.
